# 고해 반응 기능 Personas

## Persona 구성 기준

- 승인된 Hybrid story 접근에 따라 핵심 행동을 수행하는 사용자를 중심으로
  정의하고, 반응 count가 주는 의미를 확인하는 작성자 관점을 보조한다.
- 익명 식별 방식은 사용자에게 계정 생성 부담 없이 반응 경험을
  연속적으로 제공하는 제약으로 반영한다.

## P-01 조용히 위로를 전하는 익명 독자

- **역할**: 다른 사람의 고해 목록 또는 상세 내용을 읽고 반응하는
  익명 사용자.
- **목표**: 긴 문장을 작성하지 않아도 기도, 위로, 동행의 마음을
  즉시 표현하고 싶다.
- **행동 맥락**: 모바일 환경에서 여러 고해를 읽거나 한 고해를 깊이
  읽은 뒤, 마음에 맞는 반응을 하나 이상 선택하거나 다시 취소한다.
- **필요 경험**:
  - 세 반응의 의미와 현재 count를 한눈에 이해한다.
  - 본인이 이미 남긴 반응을 다시 방문해도 정확히 알아본다.
  - 조작 성공 여부를 혼동하지 않고, 실패 시 다시 시도할 수 있다.
- **주요 우려**:
  - 잘못 눌러 원치 않는 반응을 남기는 것.
  - 처리 중 중복 요청으로 count가 불명확해지는 것.
  - 새로고침이나 상세 이동 후 본인의 선택 표시가 달라지는 것.

## P-02 반응을 확인하는 고해 작성자

- **역할**: 본인의 고해 또는 동일한 공간의 고해가 받은 반응을
  살펴보는 익명 작성자.
- **목표**: 누군가 기도하거나 함께해 준다는 신호를 부담 없이
  확인하고 싶다.
- **행동 맥락**: 목록 카드 또는 상세 화면에서 누적 반응 count를
  살펴본다.
- **필요 경험**:
  - 모든 고해에서 같은 세 반응과 안정적인 count 표현을 본다.
  - 반응이 아직 없어도 `0`으로 명확하게 표시되어 기능을 이해한다.
- **주요 우려**:
  - 화면마다 반응 표시가 달라 신뢰하기 어려워지는 것.
  - 누락된 타입 때문에 반응 기능이 고장 난 것으로 오해하는 것.
